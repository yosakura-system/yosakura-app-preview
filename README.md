# 世桜アプリ（本部直営店 運用版）

本部直営店で実際に運用するためのアプリです。データは**世桜専用の保存先**（yosakura.system のスプレッドシート／Googleドライブ）に保存され、**全端末で同期**されます。

- 利用URL: https://yosakura-system.github.io/yosakura-app-preview/
- 旧・公開デモ（従来のまま・別の保存先）: https://yosakura-system.github.io/yosakura-app-demo/

## 主な画面

| 画面 | 内容 |
|---|---|
| **今日出すもの** | その日に提出するものと締切、未提出が一目で分かる |
| **オープン写真の提出** | 開店時の写真を提出（写真がないと提出できません） |
| **一食目写真／日報** | 従来どおり提出 |
| **提出履歴** | 直近7日の提出・判定 |
| **報告の確認（受信箱）**（本部） | 現場からの報告を確認して「対応済み」にする |
| **加盟店・提出物管理**（本部） | 全店の提出状況・未提出の抽出・連絡文のコピー・判定・本部確認 |
| **アプリへのご意見** | 使ってみて気づいたことを送る（全員で共有） |

## 現在の状態

- 提出の有無は**実際の提出データから自動判定**しています。
- **AI判定は未接続**のため、本部が手動で判定します（接続後は同じ欄にAI結果が入ります）。
- **LINE通知は未接続**のため、連絡文をコピーして手動送信します。
- 写真・動画・提出データは**90日で自動削除**されます（設定・ご意見は削除されません）。
- 準備中の画面には「準備中」と表示しています。

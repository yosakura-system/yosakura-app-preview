# 世桜アプリ プレビュー環境（本部メンバー確認用）

このリポジトリは、**本部直営店での実運用に向けた検証用のプレビュー**です。
**公開版（yosakura-app-demo）とは別**で、こちらを操作しても公開版には影響しません。

- プレビュー: https://yosakura-system.github.io/yosakura-app-preview/
- 公開版（従来のまま・未変更）: https://yosakura-system.github.io/yosakura-app-demo/

## 今回、確認していただきたいこと（提出管理）

7月30日の仕組みMTGでのご決定を反映し、**本部だけで一連の流れが完結する**形にしています。

| 画面 | 見ていただきたい点 |
|---|---|
| **今日出すもの** | その日に出すものが一覧で出るか。締切・残り件数が分かるか |
| **オープン写真の提出** | 撮影→提出まで迷わないか（写真がないと提出できません＝提出漏れ防止） |
| **一食目写真／日報** | 従来どおり提出できるか |
| **提出物管理（本部）** | 全店の提出状況が一目で分かるか。「未提出のみ」で絞れるか |
| **未提出の連絡文コピー** | そのままLINEへ貼れる文面か |
| **判定・本部確認** | 基準内／要確認／基準外、本部確認済、翌日改善済が付けられるか |
| **提出履歴** | 直近7日の提出・判定が追えるか |

## 現在の状態（正直な注記）

- **提出の有無は、実際の提出データから自動判定**しています（未提出は機械的に抽出）。
- **AI判定は未接続**のため、本部が**手動で判定**する形です（接続後は同じ欄にAI結果が入ります）。
- **LINE通知は未接続**のため、**連絡文をコピー**して手動送信する形です。
- 判定・本部確認・オープン写真・定休日は**全端末で共有**されます（本部メンバー全員で同じ状況が見えます）。
- 写真の自動削除は**停止**しています（保存期間が確定するまで削除しません）。
